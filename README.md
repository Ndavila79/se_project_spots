### Tech Stack

- HTML
- CSS
- Figma
- Images
- Grid Container
- Resposive Design
- JavaScript
- OOP
- Api
- WebPack



**Intro**

This project is made so all the elements are displayed correctly on popular screen sizes with the layouts displayed on the figma brief containing the layout on how the webpage should appear. The functionality of this project is also usage of grid containers to layout the images, create buttons to post, edit the profile, a like button to like the image, and to create card titles to describe the images displayed on the mark-up page. It is responsive, interactive web application built to match the layouts provided in the Figma design brief. The goal was to recreate the UI precisely across popular screen sizes while implementing dynamic functionality using modern JavaScript practices.

The application allows users to:

Edit their profile information

Update their avatar

Create new image cards

Like/unlike cards

Delete cards

View images in a preview modal

All card data and user information is synced with a remote server through an API.
